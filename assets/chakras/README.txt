HOW TO SET THE DEFAULT VASTU SHAKTI CHAKRA IMAGE
================================================

The app loads its default chakra from:
    assets/chakras/vastu-shakti-chakra.png

TO REPLACE IT WITH YOUR COLORED VASTU WHEEL:
1. Save your chakra image (the colored 360-degree wheel with directions,
   devata names, zones and organs) onto your computer.
2. Rename it exactly to:  vastu-shakti-chakra.png
3. Copy it into this folder, replacing the existing file.
4. Reload the app (Cmd+Shift+R). It will use your image automatically.

REQUIREMENTS FOR BEST RESULTS:
- Square image (equal width & height) keeps the circle centered.
- Transparent background (PNG) so the floor plan shows through the gaps.
- NORTH at the TOP of the image (12 o'clock). The app aligns the top of
  the image to the plan's North, so this is important.

NOTE: You can also just click "Upload custom chakra" in the app sidebar at
any time to use a different wheel without replacing this file.
